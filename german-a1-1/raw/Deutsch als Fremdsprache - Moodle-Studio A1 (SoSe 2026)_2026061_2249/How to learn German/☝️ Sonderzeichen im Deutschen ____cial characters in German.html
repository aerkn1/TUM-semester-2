In this Moodle-Course you will need to write words with special characters. If you use a computer with a German keyboard, you will easily find them. If you have a computer with another keyboard, you can use the Alt-key and three digits to type the special characters (On laptops you have to activate and use the numeric keypad):

Ä : Alt + 142 ä : Alt + 132 ß: Alt + 225
Ö : Alt + 153 ö : Alt + 148
Ü : Alt + 154 ü : Alt + 129  


If you cannot write the special characters, you can also write them as follows:

ä → ae
ö → oe
ü → ue
ß → ss

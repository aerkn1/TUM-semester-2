# Chapter 05: Promotion And Communication - Exam Cheatsheet

Source note: [chapter-05-promotion-communication.md](chapter-05-promotion-communication.md)

Created: 2026-07-15

Exam context: Marketing exam on 2026-07-22 is a 90-minute written exam. Promotion questions can ask for campaign design, media calculations, WOM/eWOM reasoning, or persuasion-knowledge interpretation. This sheet does not mark `First Pass` as completed.

## Core Exam Move

```text
Audience -> communication objective -> 5Ms -> message/media/timing
-> metric choice -> effect interpretation -> persuasion/trust trap.
```

Promotion is not "make an ad." It is managed meaning exchange with measurable intended effects.

## 5Ms Campaign Router

| M | Decision | Exam question |
|---|---|---|
| Mission | goal and target effect | What should change? |
| Money | budget | What resources are justified? |
| Message | content and execution | What meaning should be encoded? |
| Media | channel, reach, frequency, timing | Where and how often? |
| Measurement | pre/post tests and control | Did the intended effect happen? |

Complete objective checklist:

```text
KPI -> baseline -> desired change -> target group/geography
-> planning horizon -> link to marketing/corporate goal.
```

## Push, Pull, And Effect Hierarchy

| Concept | Meaning | Trap |
|---|---|---|
| Push | communication pressure toward wholesalers/retailers | not "aggressive tone" |
| Pull | final-customer demand pulls through the channel | not "passive marketing" |
| AIDA | Attention -> Interest -> Desire -> Action | heuristic, not guaranteed journey |
| Cognitive goal | awareness, knowledge | not automatically purchase |
| Affective goal | attitude, image, emotion | needs suitable measures |
| Conative goal | trial, search, purchase, repeat | behavior layer |

## Media Metrics

```text
GRPs = reach percentage * average frequency
CPT/CPM = advertising cost / audience in thousands
weighted CPT = CPT / target-group share
NPS = % promoters - % detractors
```

| Metric | Measures | Cannot prove alone |
|---|---|---|
| Reach | opportunity for exposure | attention or persuasion |
| Frequency | average exposures among reached audience | message quality |
| GRPs | total contact pressure | unique reach |
| CPT | cost per thousand | target relevance |
| Weighted CPT | cost corrected for target fit | sales or brand effect |
| Recognition | identifying seen content with cue | unaided memory |
| Aided recall | remembering with cue | spontaneous salience |
| Unaided recall | remembering without cue | positive attitude |
| NPS | recommendation disposition | profit or causality |

Media choice sentence:

```text
Choose the medium that fits the target and objective, not simply the lowest raw CPT.
```

## Timing Policies

| Policy | Pattern | Use when |
|---|---|---|
| Blitz | concentrated burst | launch, short event, rapid awareness |
| Even | continuous level | stable demand and ongoing memory |
| Pulsing | separated bursts | periodic demand or event cycles |
| Pulsing/maintenance | baseline plus bursts | preserve memory and create peaks |

## WOM, eWOM, Influencers, PKM

| Concept | Exam-safe distinction |
|---|---|
| WOM | person-to-person commercial-topic communication perceived as non-commercial. |
| eWOM | online consumer statements that are persistent, searchable, scalable, and often anonymous. |
| Credibility | perceived believability/truthfulness. |
| Helpfulness | usefulness for the purchase decision. |
| Influencer marketing | marketer uses influencer to pursue business objective; often native advertising. |
| Persuasion Knowledge Model | consumers recognize persuasion attempts and cope through acceptance, resistance, negotiation, ignoring, or strategic use. |

Yale logic for review persuasiveness:

```text
Who says what to whom?
Sender/platform -> message -> receiver -> credibility/helpfulness.
```

## Written-Exam Answer Skeletons

5M campaign case:

```text
1. Define target audience and complete objective.
2. Mission: target effect.
3. Money: budget method, ideally objective-and-task.
4. Message: content/execution fit with positioning.
5. Media: reach, frequency, target fit, timing.
6. Measurement: pre-test/post-test and KPI layer.
```

Media calculation case:

```text
Raw CPT -> target-group share -> weighted CPT
-> choose medium -> explain why target fit can beat broad cheap reach.
```

Influencer/disclosure case:

```text
Agent -> target -> persuasion attempt -> disclosure
-> persuasion knowledge activated? -> coping response
-> credibility/helpfulness/brand fit.
```

## Traps And Corrections

| Trap | Correction |
|---|---|
| Communication = advertising only. | Include internal, external, interactive, WOM/eWOM, PR, direct, digital. |
| High reach means attention. | Reach is opportunity for exposure. |
| Cheapest CPT is best. | Correct for target fit and objective. |
| Attention-grabbing means effective. | Match to cognitive, affective, or behavioral objective. |
| Paid influencer post is independent WOM. | It is influencer/native advertising and can activate PKM. |
| Credibility = helpfulness. | A review can be believable but not useful, or useful but not fully trusted. |
| Persuasion knowledge means rejection. | Coping includes acceptance and other adaptive responses too. |

## Last Line

```text
Campaign answer = audience + objective + 5Ms + media metrics + effect measurement + persuasion-risk check.
```

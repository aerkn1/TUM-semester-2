# Session 05: Technology And Organization - Exam Cheat Sheet

Source note: [session-05-technology-and-organization.md](session-05-technology-and-organization.md)

Created: 2026-07-15

Use this sheet for rapid exam recall. It does not replace the full note and does not mark `First Pass` as completed.

## Core Exam Move

```text
Define technology broadly -> classify technical features -> analyze use in practice
-> explain structure/control implications.
```

## Definition

```text
Organizational technology = means by which inputs are transformed into outputs,
including tools, machines, methods, procedures, skills, and knowledge.
```

Basic process:

```text
Inputs -> core technology / transformation process -> outputs
```

Levels of analysis:

| Level | Diagnostic question |
|---|---|
| Task | How does the technology change a specific activity? |
| Department | How does it change unit coordination? |
| Organization | How does it reshape broader processes? |
| Society | How does it affect institutions and practices beyond one firm? |

## Modernist Typology Router

| Thinker | Dimensions | Use in answer |
|---|---|---|
| Woodward | technical complexity: small batch, mass production, continuous process | structure effectiveness depends on technology |
| Thompson | standardization of inputs/outputs and transformation process | long-linked, mediating, intensive |
| Perrow | task variability x task analyzability | routine, engineering, craft, nonroutine |

Perrow quick matrix:

| Variability | Analyzability | Type | Coordination implication |
|---|---|---|---|
| low | high | routine | standardize |
| high | high | engineering | experts with known methods |
| low | low | craft | skill and apprenticeship |
| high | low | nonroutine | judgment, expertise, flexible coordination |

Exam-safe insight:

```text
High variability plus low analyzability creates the strongest need for judgment and flexible coordination.
```

## Modernist Vs Symbolic-Interpretive

| View | Question | Example answer |
|---|---|---|
| Modernist | What type of technology is this and what structure fits it? | classify task variability and analyzability |
| Symbolic-interpretive | How do actors interpret and enact the technology? | same spreadsheet becomes coordination tool, control instrument, workaround, or conflict arena |

SCOT:

```text
Different social groups shape technology through competing interpretations, and technology later shapes society.
```

Adaptive structuration:

```text
Technology shapes social structure, and people shape technology through routines, improvisation, and use.
```

## Technology-In-Practice Toolkit

| Concept | Ask |
|---|---|
| Affordances | What action does the technology make possible? |
| Constraints | What action does it make difficult or costly? |
| Technological frames | How do different groups interpret it? |
| Enactment | How is it actually used in everyday practice? |

## Control Angle

Technology can:

- coordinate work
- make performance visible
- standardize decisions
- enable surveillance
- shift power over information
- provoke resistance or workarounds

Exam sentence:

```text
A dashboard introduced as coordination support may become a control instrument if it monitors, compares, and disciplines visible behavior.
```

## Trap Corrections

| Trap | Correction |
|---|---|
| "Technology = machines." | Include methods, procedures, skills, and knowledge. |
| "Same tool, same effect." | Analyze enactment and technological frames. |
| Only classifying technology | Add practice, control, and power implications. |
| Ignoring level | State task, department, organization, or society level. |

## Last Line

```text
Technology questions need both classification and enactment: what the technology is, and what people make it become in practice.
```

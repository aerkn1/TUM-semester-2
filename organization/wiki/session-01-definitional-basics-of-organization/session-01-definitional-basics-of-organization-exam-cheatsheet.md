# Session 01: Definitional Basics Of Organization - Exam Cheat Sheet

Source note: [session-01-definitional-basics-of-organization.md](session-01-definitional-basics-of-organization.md)

Created: 2026-07-15

Use this sheet for rapid exam recall. It does not replace the full note and does not mark `First Pass` as completed.

## Core Exam Move

```text
Define organization -> test the case against the criteria -> choose a perspective
-> explain the organizing problem -> name the trap.
```

## Definition To Memorize

An organization is a:

```text
social entity, goal-directed, deliberately structured, and linked to the external environment.
```

| Criterion | Ask in a case | Typical evidence |
|---|---|---|
| Social entity | Who are the actors and relationships? | members, employees, volunteers, teams |
| Goal-directed | What outcomes are pursued? | mission, campaign, service, product, reputation |
| Deliberately structured | How is coordinated action organized? | roles, rules, routines, hierarchy, teams |
| Environment-linked | Which external actors/conditions matter? | customers, university, regulators, sponsors, labor market |

Borderline-case sentence:

```text
Even without a classic hierarchy, the case can be organization-like if actors coordinate around goals through recognizable structures and environmental relations.
```

## Views Router

| View | Core claim | Use when the case shows | Trap |
|---|---|---|---|
| Instrumental | Organization as management instrument | planned rules, structure, implementation | ignores informal/dysfunctional behavior |
| Institutional | Organization as whole social system | goals, boundaries, functions, dysfunctions | too broad if no structure is shown |
| Rational system | formal goals plus formalized structure | org chart, KPI, hierarchy, procedures | overstates written rules |
| Natural system | multiple interests plus informal behavior | motivation, power, workarounds, status | underplays formal design |
| Open system | flows embedded in wider environment | suppliers, regulators, platforms, resources | makes boundaries ambiguous |

## Organizing Problems

| Problem | What to say |
|---|---|
| Task structuring | The organization divides work and coordinates interdependent activity. |
| Motivation | People must contribute beyond mere formal compliance. |
| Uncertainty | The organization must handle incomplete information and external change. |
| Emergence | Local practices, informal norms, and workarounds reshape the formal design. |
| Change | Structures must be adapted, reproduced, or transformed over time. |

## Must-Know Distinctions

| Distinction | Exam-safe wording |
|---|---|
| Formal structure vs organizing in practice | Formal structure defines official roles, rules, reporting lines, and decision rights; organizing in practice is how people enact, adapt, or bypass them. |
| Management as actors vs activity | Managers are formal role holders; management as activity means planning, organizing, staffing, leading, and controlling can be distributed across many actors. |
| Example vs definition | A company is an example, not the definition. Always name the criteria first. |

## Case Router

Student consulting club:

```text
Social entity: members, board, project teams.
Goals: learning, consulting projects, reputation, recruiting.
Structure: board roles, project leads, application process.
Environment: TUM, firms, alumni, sponsors, labor market.
Likely problems: volunteer motivation, turnover, role clarity, knowledge transfer.
```

Fridays for Future:

```text
Organization-like because it has actors, goals, coordination, and environment links.
Less classic because boundaries and hierarchy are fluid.
Use open-system and natural-system views, not only rational-system view.
```

## Trap Corrections

| Trap | Correction |
|---|---|
| "Legal status proves organization." | Legal form is not enough; test social entity, goals, structure, and environment. |
| "Organizations have one clear goal." | They often contain multiple, conflicting, or changing goals. |
| "Formal chart explains behavior." | Add organizing in practice: informal communication, workarounds, local problem solving. |
| "One perspective is enough." | Applied cases often need rational + natural + open-system comparison. |

## Last Line

```text
An organization is not just an org chart. It is coordinated social action around goals, structured in practice, and embedded in an environment.
```

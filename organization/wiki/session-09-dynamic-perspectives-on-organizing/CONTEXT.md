# Ubiquitous Language: Session 09 Dynamic Perspectives On Organizing

## Change And Process Language

| Term | Definition | Aliases to avoid |
|---|---|---|
| **Organizational Change** | Difference in organizational state, form, or properties across time, together with the process through which it emerges. | announcement, implementation project only |
| **State Comparison** | Comparison of an entity at two or more moments to identify what changed. | process explanation |
| **Change Process** | Sequence and interaction of mechanisms through which change unfolds. | before/after difference |
| **Objectification** | Treating change as a named object, theme, symbol, or variable. | complete process analysis |
| **Distinction** | Treating change as differences among states or phases over time. | unfolding |
| **Unfolding** | Treating change as interacting mechanisms, feedback, reversals, and trajectories over time. | linear stage sequence |
| **Change Management** | Deliberate effort to influence the direction, adoption, and institutionalization of change. | guaranteed control of change |
| **Adoption** | Actual use and integration of a new practice in everyday work. | launch, login, training attendance |
| **Institutionalization** | Embedding new behavior in routines, roles, measures, incentives, and cultural expectations. | temporary compliance |
| **Resistance** | Behavior or interpretation that slows, redirects, contests, or rejects change. | irrational obstruction |

## Kotter Language

| Term | Definition | Aliases to avoid |
|---|---|---|
| **Urgency** | Shared recognition that maintaining the current state carries meaningful risk or lost opportunity. | panic |
| **Guiding Coalition** | Credible group with authority, expertise, networks, and commitment to mobilize change. | senior management only |
| **Change Vision** | Clear picture of the desired future and why it matters. | project slogan |
| **Barrier Removal** | Changing structures, resources, skills, rules, or incentives that prevent action. | motivational speech |
| **Short-Term Win** | Early credible result that demonstrates progress and supports momentum. | vanity metric |
| **Anchoring** | Connecting new behavior to culture, systems, staffing, and performance management. | announcing completion |

## Lewin And Force-Field Language

| Term | Definition | Aliases to avoid |
|---|---|---|
| **Unfreeze** | Destabilize attachment to the current equilibrium and make alternatives possible. | create chaos |
| **Move** | Experiment with and learn new behaviors, processes, or structures. | technical installation only |
| **Refreeze** | Stabilize an effective new pattern through routines and reinforcement. | permanent rigidity |
| **Driving Force** | Pressure supporting movement toward the desired state. | benefit only |
| **Restraining Force** | Pressure preserving the current state or redirecting change. | bad attitude |
| **Force Field Analysis** | Mapping driving and restraining forces to decide which pressures to strengthen or reduce. | pros-and-cons list without actors |

## ADKAR Language

| Element | Definition | Diagnostic correction |
|---|---|---|
| **Awareness** | Understanding why change is needed. | Knowing the announcement is not enough |
| **Desire** | Willingness to support and participate. | Awareness does not guarantee commitment |
| **Knowledge** | Knowing how to change and what the future process requires. | Training completion is not ability |
| **Ability** | Demonstrated capacity to perform under real conditions. | Theoretical knowledge is insufficient |
| **Reinforcement** | Feedback, recognition, accountability, and system support that sustain behavior. | One reward does not institutionalize change |

## Transition Language

| Term | Definition | Aliases to avoid |
|---|---|---|
| **Change** | External event or altered organizational arrangement. | transition |
| **Transition** | Internal psychological reorientation through which people adapt to change. | rollout phase |
| **Ending, Losing, Letting Go** | Recognition and processing of what identity, routine, status, or certainty is ending. | resistance stage only |
| **Neutral Zone** | Ambiguous in-between period in which old patterns weaken and new patterns remain unstable. | no progress |
| **New Beginning** | Adoption of new meaning, identity, competence, and commitment. | launch day |

## Appreciative Inquiry Language

| Term | Definition | Aliases to avoid |
|---|---|---|
| **Appreciative Inquiry** | Participative change approach that studies strengths and peak experiences to design a desired future. | positivity workshop |
| **Discover** | Identify situations where the organization already performs well. | ignore failures |
| **Dream** | Imagine a desirable future based on discovered strengths. | unrealistic wish list |
| **Design** | Specify structures, relationships, and practices supporting the future. | vision statement only |
| **Destiny/Deploy** | Experiment, learn, and sustain participant-led action. | automatic implementation |

## SCARF Language

| Domain | Definition | Change threat example |
|---|---|---|
| **Status** | Perceived relative importance, competence, or standing. | expert role loses prestige |
| **Certainty** | Ability to predict relevant events and expectations. | unclear data-use policy |
| **Autonomy** | Perceived control over choices and action. | mandatory tool removes discretion |
| **Relatedness** | Sense of trust, safety, and belonging with others. | new system weakens team interaction |
| **Fairness** | Perception that procedures and outcomes are justifiable and consistent. | monitoring burden falls unevenly |

## Relationships Between Canonical Terms

- **State Comparison** shows what changed, while **Change Process** explains how it unfolded.
- **Objectification**, **Distinction**, and **Unfolding** represent increasing attention to temporal mechanisms.
- **Kotter** addresses organization-wide mobilization; **ADKAR** addresses individual adoption.
- **Lewin** diagnoses movement from an equilibrium; **Force Field Analysis** identifies pressures maintaining or changing it.
- **Change** triggers **Transition**, but different actors may transition at different speeds.
- **SCARF** can explain why **Desire** is weak even when **Awareness** and **Knowledge** are high.
- **Short-Term Wins** support **Reinforcement**, but only if they represent meaningful outcomes.
- **Institutionalization** requires formal design and informal acceptance.

## Framework Selection Router

| Symptom | Primary framework | Complementary check |
|---|---|---|
| No urgency or coalition | **Kotter** | Power and stakeholder analysis |
| Current routine remains stable | **Lewin/Force Field** | Incentives and informal norms |
| Different people fail at different adoption points | **ADKAR** | Role-specific diagnosis |
| Loss, identity, or ambiguity dominates | **Bridges Transition Model** | SCARF status/certainty |
| Engagement is low but strengths exist | **Appreciative Inquiry** | Do not suppress failures or conflict |
| Surveillance, autonomy, or fairness fear | **SCARF** | Governance and structural redesign |

## AI Tool Case Language

| Case fact | Canonical diagnosis |
|---|---|
| Employees fear surveillance | **SCARF autonomy/fairness threat** plus governance problem |
| Team leads fear reduced autonomy | **Status** and **Autonomy** threat; possible weak **Desire** |
| IT says the tool is ready | Technical completion without behavioral **Adoption** |
| Teams keep old spreadsheets | Strong **Restraining Forces**, weak **Ability** or trust |
| Management wants progress in three months | Need credible **Short-Term Wins**, not vanity metrics |

## Example Dialogue

> Sponsor: The tool is technically ready, so why are teams still using spreadsheets?
>
> Change lead: Technical readiness is not adoption. Awareness exists, but Desire and Ability are weak because team leads expect status and autonomy loss.
>
> Sponsor: What should we do first?
>
> Change lead: Map restraining forces, clarify surveillance governance, build a guiding coalition, and run a bounded pilot with meaningful short-term wins.

## Flagged Ambiguities And Recommendations

| Ambiguity | Canonical recommendation |
|---|---|
| Change versus transition | Use **change** for external arrangements and **transition** for internal adaptation |
| Resistance versus obstruction | Diagnose the underlying interest, threat, capability, or structural barrier before judging intent |
| Knowledge versus ability in ADKAR | Knowledge is knowing how; ability is performing under real conditions |
| Refreeze in continuous environments | Interpret it as stabilizing an effective pattern, not making the organization permanently static |
| Short-term win versus activity metric | A win demonstrates valued outcome improvement, not merely system usage |
| SCARF as implementation model | Use SCARF to diagnose social threat, then choose concrete governance and implementation actions |

## Exam Traps And Correction Rules

- **Trap:** list framework components without applying case evidence. **Correction:** one fact, one mechanism, one intervention for each component.
- **Trap:** choose a model because it is famous. **Correction:** justify level of analysis and problem fit.
- **Trap:** blame resistance on communication. **Correction:** test interests, capability, workload, identity, power, and incentives.
- **Trap:** compare models only by number of stages. **Correction:** compare mechanism, level, strength, and blind spot.
- **Trap:** claim one model solves everything. **Correction:** add a complementary lens for the primary blind spot.

## Cheat-Sheet Language

```text
What changed? -> state comparison
How/why? -> unfolding process

Kotter = mobilize and anchor
Lewin = equilibrium and forces
ADKAR = individual adoption
Bridges = psychological transition
Appreciative Inquiry = strengths and participation
SCARF = social threat/reward
```

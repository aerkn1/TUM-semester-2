## Core Exam Move

```text
Do not trust the label -> apply four-problem canvas -> compare to similar organizations
-> assess novelty, strengths, and limits.
```

## Novelty Test

A form is "new" only if it solves one or more universal organizing problems differently relative to comparable organizations.

Process:

1. Hold the goal as stable as possible.
2. Choose comparison group.
3. Identify which organizing problem changed.
4. Assess the bundle, not one isolated feature.

## Four Universal Problems

| Problem | Core question |
|---|---|
| Task division | How is the goal decomposed into tasks? |
| Task allocation | Who performs which tasks? |
| Reward provision | Why do actors contribute? |
| Information provision | How do actors receive the information needed for work? |

Exam sentence:

```text
"Agile", "network", or "platform" is not the answer; the answer is which organizing problem is solved differently and how.
```

## Why New Forms Become Attractive

Environmental pressure:

- volatile markets
- digitalization and intelligent systems
- disintermediation/platforms
- geopolitical shocks and crises
- climate/ecological pressure
- social demands for fairness, ethics, meaning

Design implication:

```text
New forms are responses to adaptability, coordination, legitimacy, and capability problems in turbulent environments.
```

## Open Source And Wikipedia Canvas

| Form | Task division | Task allocation | Reward provision | Information provision |
|---|---|---|---|---|
| Open source | architecture evolves through modules/issues | contributors self-select | use value, intrinsic motivation, reputation | visible code, issues, docs, platform |
| Wikipedia | pages/topics emerge and evolve | contributors self-select edits | intrinsic and reputational | edit history, rules, online artifacts |

Key point:

```text
These forms shift allocation away from managerial assignment and rely heavily on transparent digital artifacts.
```

## Agile And Self-Management

Agile logic:

```text
short-cycle learning + customer feedback + cross-functional collaboration + response to change.
```

Self-management correction:

```text
Self-management does not mean no structure; it means authority is structured differently.
```

## Network Organization

```text
Network organization = legally independent actors coordinate through relationships, trust, complementary capabilities, and mutual adjustment.
```

Pros:

- access distributed expertise
- flexibility and scalability
- innovation through complementarity
- lower need for internal ownership

Cons:

- coordination costs
- unclear accountability
- partner dependence
- trust/knowledge leakage risks
- harder governance/conflict resolution

Network vs ecosystem:

```text
Network organization = relationship-based coordination among independent actors.
Ecosystem = broader value system around flows, participants, and outcomes.
```

## Holacracy

Core correction:

```text
Holacracy reduces managerial hierarchy but increases formal governance.
It is less boss-centered, not less structured.
```

Elements:

- role: purpose, accountabilities, authority domains
- circle: semi-autonomous unit
- lead link: role assignment
- rep link: upward representation
- facilitator/secretary: process and records
- governance meeting: changes roles/policies/authority
- tactical meeting: operational updates and tensions

Holacracy four-problem answer:

| Problem | Answer |
|---|---|
| Task division | explicit roles and circles |
| Task allocation | circle governance and lead-link mechanisms |
| Reward provision | purpose, autonomy, role contribution, peer accountability |
| Information provision | meetings, role records, governance decisions, tools |

## Trap Corrections

| Trap | Correction |
|---|---|
| "New because trendy." | Apply the four-problem novelty test. |
| "Network has no hierarchy." | It has governance, contracts, trust, boundary roles. |
| "Holacracy has no structure." | It replaces managerial hierarchy with formal governance. |
| Forgetting motivation/info | Reward and information provision are part of the canvas. |

## Last Line

```text
New-form questions are design-diagnosis questions: what changed in task division, task allocation, rewards, or information?
```

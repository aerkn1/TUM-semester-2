# Ubiquitous Language: Sessions 07-08 Informal Organization

Source note: `session-07-08-informal-organization.md`
Course: Organization
Definition sources: local lecture decks and Motorica cases for term discovery; standard organization-theory knowledge used where the slides name or illustrate a concept without a standalone definition.

## Formal And Informal Organizing

| Term | Definition | Aliases to avoid |
|---|---|---|
| **Formal Organization** | Deliberately designed rules, roles, authority relations, incentives, structures, and sanctions. | what actually happens |
| **Informal Organization** | Emergent norms, relationships, communication channels, status orders, knowledge flows, and influence patterns through which work is enacted. | random behavior, office gossip only |
| **Enacted Organization** | The recurring pattern produced when actors interpret and use formal arrangements in practice. | organization chart |
| **Structuration** | Recursive process in which structure enables/constrains action and action reproduces/changes structure. | structure determines behavior |
| **Signification** | Structural system of meanings used in communication. | formal communication only |
| **Domination** | Structural control over resources that enables power. | bullying only |
| **Legitimation** | Structural norms and standards backed by sanctions. | legal validity |
| **Line Of Flight** | Informal escape route that bypasses or undermines tight hierarchy or bureaucracy. | any rule violation |

## Culture Language

| Term | Definition | Aliases to avoid |
|---|---|---|
| **Organizational Culture** | Collective meanings learned and enacted through values, assumptions, symbols, stories, norms, and practices. | employee happiness, stated values only |
| **Artifact** | Visible cultural indicator such as architecture, language, ritual, story, meeting pattern, or reward. | direct proof of culture |
| **Espoused Value** | Stated principle or standard describing what the organization says matters. | basic assumption |
| **Basic Assumption** | Taken-for-granted belief that shapes what members perceive as natural, correct, or possible. | written policy |
| **Strong Culture** | Culture with clear norms, wide dissemination, and deep anchoring. | good culture |
| **Subculture** | Distinct meaning system within an organization, often based on profession, region, task, or space. | automatically dysfunctional silo |
| **Enhancing Subculture** | Subculture that reinforces dominant organizational values. | counterculture |
| **Orthogonal Subculture** | Subculture that remains distinct without directly opposing dominant values. | neutral employee group |
| **Counterculture** | Subculture that challenges dominant values and expectations. | any disagreement |
| **Culture Clash** | Coordination problem caused by conflicting assumptions, identities, norms, or standards of legitimate evidence. | personality clash |
| **Uniqueness Paradox** | Organizations tell apparently unique identity stories that often use common story themes. | false story |

## Knowledge Language

| Term | Definition | Aliases to avoid |
|---|---|---|
| **Data** | Signs organized by syntax but not yet interpreted for a decision. | knowledge |
| **Information** | Data given meaning. | raw data |
| **Knowledge** | Information connected to context, relationships, and practical understanding. | document repository |
| **Competency** | Ability to perform adequately using knowledge in action. | information possession |
| **Tacit Knowledge** | Experiential know-how that is intuitive and difficult to articulate fully. | secret information, implicit knowledge without clarification |
| **Explicit Knowledge** | Knowledge that can be articulated, codified, and transferred relatively easily. | complete understanding |
| **Knowledge Identification** | Locating what knowledge exists and where it resides. | knowledge creation |
| **Knowledge Externalization** | Making tacit judgment discussable through concepts, examples, models, or documents. | perfect codification |
| **Knowledge Sharing** | Moving knowledge across actors or units so others can understand and use it. | uploading a file |
| **Knowledge Retention** | Preserving knowledge so it remains available despite time or employee turnover. | data backup only |

### SECI Conversion

| Term | Conversion | Canonical example |
|---|---|---|
| **Socialization** | tacit -> tacit | observation, mentoring, joint practice |
| **Externalization** | tacit -> explicit | expert explains judgment criteria |
| **Combination** | explicit -> explicit | integrate reports, rules, and datasets |
| **Internalization** | explicit -> tacit | learning by doing until a method becomes skill |

## Power And Conflict Language

| Term | Definition | Aliases to avoid |
|---|---|---|
| **Power** | Capacity to shape decisions, behavior, access, or outcomes. | formal authority only |
| **Formal Authority** | Legitimate decision right attached to an official role. | all power |
| **Organizational Politics** | Mobilization of power and coalitions around interests and contested decisions. | unethical behavior by definition |
| **Dependency** | Condition in which one actor needs resources or actions controlled by another. | weakness only |
| **Centrality** | Position through which important workflows, information, or resources pass. | seniority |
| **Non-Substitutability** | Difficulty of replacing a unit's resources, expertise, or contribution. | monopoly in a legal sense |
| **Uncertainty Coping** | Ability to reduce uncertainty that matters to the organization. | forecasting alone |
| **Organizational Conflict** | Perceived interference between actors' goals, efforts, status, resources, or outcomes. | open argument only |
| **Task Conflict** | Disagreement about ideas, evidence, or how work should be performed. | relationship conflict |
| **Relationship Conflict** | Interpersonal tension, dislike, or emotional friction. | useful debate |
| **Status Conflict** | Dispute over respect, rank, voice, or relative standing. | role ambiguity only |
| **Resource Conflict** | Competition over scarce budget, time, staff, information, or access. | task conflict only |
| **Political Conflict** | Struggle over whose interests, evidence, or agenda controls a decision. | party politics |
| **Superordinate Goal** | Shared outcome important enough to require cooperation across groups. | vague common purpose |
| **Cybernetic Control** | Feedback system linking goals, measures, rewards, action, outcomes, and corrective resource allocation. | surveillance only |

## Relationships Between Canonical Terms

- **Formal Organization** provides resources and constraints that actors interpret through **Structuration**.
- Repeated action produces the **Enacted Organization**, which can reproduce or change formal structure.
- **Artifacts** may indicate **Espoused Values** or **Basic Assumptions**, but interpretation requires multiple observations.
- **Strong Culture** can improve coordination while making **Culture Clash** and learning failures harder to surface.
- **Tacit Knowledge** becomes more shareable through **Externalization**, but never becomes perfectly codified.
- **Power** becomes political when actors use it to promote interests through **Organizational Politics**.
- **Task Conflict** can be productive; **Relationship Conflict** and **Status Conflict** usually increase escalation risk.
- **Cybernetic Control** directs attention through measures and rewards, which can create **Resource Conflict** and **Political Conflict**.

## Motorica Canonical Diagnosis

| Case evidence | Canonical term | Why |
|---|---|---|
| Heritage rooms, classic vehicles, executive proximity | **Artifact** and **Status Power** | Space communicates identity and standing |
| "Protect the badge" | **Espoused Value** approaching a **Basic Assumption** | Brand continuity defines legitimate judgment |
| Brand versus Digital evidence standards | **Culture Clash** | Groups disagree about what counts as valid evidence |
| Senior campaign intuition | **Tacit Knowledge** | Learned through experience and difficult to articulate |
| Dashboards and tests | **Explicit Knowledge** | Codified, measurable, but context-dependent |
| Agency access versus CFO-requested data | **Resource Control** and **Non-Substitutability** | Each unit controls valued resources |
| Budget cut and senior attention | **Resource Conflict** | Scarcity intensifies competition |
| "Who decides what evidence counts?" | **Political Conflict** | Decision criteria are contested |

## Example Dialogue

> Manager: The formal process assigns Brand Strategy, Digital Growth, and Product Marketing distinct roles, but the enacted organization routes disagreement through status and informal allies.
>
> Analyst: So this is not only task conflict. Brand controls agency and board access, while Digital controls performance data, giving both departments informal power.
>
> Manager: Correct. We need a superordinate goal and an evidence-gated process that externalizes tacit brand judgment without pretending that dashboards are context-free truth.

## Flagged Ambiguities And Recommendations

| Ambiguity | Recommendation |
|---|---|
| Slides use **implicit knowledge** for intuitive, non-formalizable know-how | Write **tacit knowledge (implicit in the lecture wording)** |
| Culture is sometimes used for any shared behavior | Reserve **organizational culture** for recurring shared meanings and assumptions |
| Power is confused with authority | State whether influence comes from role, expertise, resources, access, or norms |
| Politics is treated as automatically bad | Define it neutrally as power mobilized around interests; then assess consequences |
| Conflict is classified as good or bad in general | Identify type, level, and effect on performance |
| "Better communication" is offered as a solution | Specify decision rights, knowledge conversion, evidence rules, incentives, and conflict process |

## Exam Traps And Correction Rules

- **Trap:** infer a basic assumption from one poster. **Correction:** triangulate artifacts, stories, rewards, and repeated behavior.
- **Trap:** say strong culture always improves performance. **Correction:** discuss strategic fit, learning, and flexibility.
- **Trap:** treat a database as knowledge management. **Correction:** include identification, articulation, sharing, use, retention, appraisal, and feedback.
- **Trap:** equate disagreement with relationship conflict. **Correction:** separate task, relationship, status, resource, and political dimensions.
- **Trap:** suppress all Motorica conflict. **Correction:** preserve useful evidence disagreement while reducing status and process escalation.

## Cheat-Sheet Router

```text
Formal rule -> enacted practice -> informal mechanism

Culture: artifact -> value -> assumption -> behavior
Knowledge: identify -> articulate -> share -> use -> retain
Power: resource/dependency/centrality/non-substitutability/uncertainty
Conflict: type -> level -> performance effect -> intervention
```

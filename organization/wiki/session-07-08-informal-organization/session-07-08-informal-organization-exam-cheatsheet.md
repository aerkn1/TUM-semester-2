# Sessions 07-08: Informal Organization - Exam Cheat Sheet

Source note: [session-07-08-informal-organization.md](session-07-08-informal-organization.md)

Created: 2026-07-15

Use this sheet for rapid exam recall. It does not replace the full note and does not mark `First Pass` as completed.

## Core Exam Move

```text
Start with formal arrangement -> identify informal mechanism
-> apply culture/knowledge/power/conflict theory -> recommend intervention
-> state limitation.
```

## Formal Vs Informal

| Formal organization | Informal organization |
|---|---|
| deliberate rules, roles, authority, sanctions | emergent relationships, norms, status, influence |
| how work should happen | how work is enacted in practice |
| logical consistency is intended | contradictions and workarounds can persist |

Exam sentence:

```text
Informal organization can support, modify, bypass, or oppose formal design.
```

## Structuration

```text
Structure enables and constrains action; repeated action reproduces or changes structure.
```

| Structural property | Actor experience | Feedback |
|---|---|---|
| Signification | shared meanings/language | communication confirms or changes meaning |
| Domination | resources and influence | power use reproduces or shifts control |
| Legitimation | norms and standards | sanctions reward or punish action |

## Culture Router

| Concept | Exam use |
|---|---|
| Schein artifacts | visible language, dress, rituals, stories, meetings, rewards |
| Espoused values | official principles and goals |
| Basic assumptions | taken-for-granted beliefs inferred from repeated patterns |
| Strong culture | clear, shared, deeply anchored norms |
| Subculture | professional/regional/task group meanings |
| Counterculture | directly challenges dominant values |

Trap:

```text
Do not infer basic assumptions from one artifact. Triangulate artifacts, decisions, rewards, and stories.
```

## Knowledge Router

North stairway:

```text
signs + syntax -> data -> information -> knowledge -> action -> competency -> competitiveness
```

Tacit vs explicit:

- explicit = articulable, codified, transferable
- tacit = experiential, hard to articulate, often learned by participation

SECI:

| Mode | Conversion | Example |
|---|---|---|
| Socialization | tacit -> tacit | apprentice observes expert |
| Externalization | tacit -> explicit | expert playbook |
| Combination | explicit -> explicit | integrate reports/procedures |
| Internalization | explicit -> tacit | repeated use becomes skill |

## Power, Politics, Conflict

Power = capacity to shape decisions/outcomes. Politics = mobilizing power around interests. Conflict = perceived interference with goals/outcomes.

Horizontal departmental power increases with:

```text
resource control, centrality, non-substitutability, dependency, uncertainty coping.
```

Conflict and performance:

| Level | Result | Action |
|---|---|---|
| too low | passivity, weak integration | stimulate constructive disagreement |
| moderate | task-focused improvement | maintain psychological safety |
| too high | hostility, politics, distraction | reduce escalation and repair process |

## Motorica Case Route

Do not call it a personality clash. Use this diagnosis:

```text
formal sequence unclear + brand culture/status + digital analytics knowledge
+ non-substitutable resources + task/resource/status/process conflict.
```

Intervention:

1. shared superordinate goal: credible premium demand generation
2. decision gates: brand hypothesis, digital test, technical validation, regional evidence
3. cross-functional evidence board
4. externalize tacit brand criteria
5. document digital-test limits
6. protect constructive dissent
7. feed launch learning into next cycle

## Trap Corrections

| Trap | Correction |
|---|---|
| "Informal = unofficial behavior." | Explain the coordinating mechanism. |
| "Strong culture is always good." | It can suppress criticism and learning. |
| "Tacit knowledge is secret information." | It is hard-to-articulate know-how. |
| "Power = formal authority." | Include resources, information, centrality, expertise, sanctions. |
| "Better communication fixes Motorica." | Redesign decisions, evidence, incentives, and knowledge flows. |

## Last Line

```text
Informal organization explains why the same formal design can produce different enacted behavior, power, culture, knowledge, and conflict.
```
